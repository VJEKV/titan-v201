ТИТАН Аудит ТОРО v.111 — Исправление иерархии ТМ
================================================

ЧТО ИСПРАВЛЕНО:
- ТМ теперь отображается как "КОД - Название" (ST01.0101.VE02 - Печь пиролиза)
- УСТАНОВКА отображается как "КОД - Название" (ST01.0100 - Общецеховое оборудование)
- Секция "ТМ по ПЕРЕРАСХОДУ" фильтрует только реальные ТМ (код >= 12 символов)
- Цеха и установки НЕ попадают в аналитику по ТМ

УСТАНОВКА:
1. tm_loader.py → core/tm_loader.py
2. tm_structure.json → корень проекта (рядом с app.py)
3. data_processor.py → core/data_processor.py
4. tab_finance.py → tabs/tab_finance.py

ИЕРАРХИЯ КОДОВ:
- ST01          (4 символа)  = ПРОИЗВОДСТВО
- ST01.01       (7 символов) = ЦЕХ
- ST01.0100     (9 символов) = УСТАНОВКА
- ST01.0101.VE02 (12+ символов) = ТМ (техническое место)
